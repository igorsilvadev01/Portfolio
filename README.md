# Portfólio — Igor Silva

Portfólio profissional de Igor Fernando Oliveira da Silva, desenvolvido como uma experiência estática, responsiva e acessível.

## Conteúdo

- Apresentação profissional e contatos
- Estudos de caso dos principais projetos
- Experiência e formação acadêmica
- Certificações e competências técnicas
- Tema claro/escuro e navegação responsiva
- SEO, dados estruturados e suporte a redução de movimento

## Executar localmente

Os arquivos publicados ficam em `dist/`. Use qualquer servidor HTTP estático, por exemplo:

```powershell
npm run dev
```

Abrir o arquivo diretamente também funciona, mas um servidor local representa melhor a hospedagem final.
